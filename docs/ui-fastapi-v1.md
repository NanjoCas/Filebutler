# FileButler 可视化界面与 FastAPI 设计（V1）

日期：2026-10-18

## 目标

为现有 FileButler 增加一个在本机运行的网页界面。用户可以创建多个互相隔离的对话，在同一对话中连续交互，并浏览、预览配置沙盒内的文件。FastAPI 提供本地 HTTP 接口，Agent、检索、文件操作、安全确认和 undo 继续复用现有实现。

V1 的“本地”表示网页和 FastAPI 服务运行在用户电脑上；模型仍通过当前配置调用 DeepSeek API。V1 面向单用户使用，不提供公网部署、多用户账户或权限管理。

## 用户流程

1. 启动本地服务，在浏览器打开界面。
2. 从左侧会话列表恢复旧对话，或创建新对话。
3. 在选中的对话中发送指令；Agent 可以继续读取之前的消息，并按现有流程调用工具。
4. 任务运行时查看状态；遇到需要确认的写操作时，在界面检查操作内容后允许或拒绝。
5. 查看 Agent 回复、运行费用和工具调用摘要；如有写操作，可从该轮运行发起 undo。
6. 在文件区浏览沙盒目录并预览受支持的文件。

## V1 功能需求

### 会话与聊天

- 创建、列出、打开多个对话；新对话不继承其他对话的消息。
- 会话标题根据首条用户消息自动生成，列表按最近更新时间排序。
- 同一对话支持多轮交互。服务保存 Agent 所需的完整消息历史，包括工具调用及其结果；界面以用户消息和最终回复为主展示，可折叠查看工具调用摘要。
- 刷新或重启服务后，会话及已完成消息仍可恢复。
- 每个对话同时只运行一个任务。运行中重复提交返回明确错误；其他会话可以继续查看。
- 页面展示排队/运行/等待确认/完成/失败状态，以及每轮的模型、费用、耗时和撤销状态。

### 文件浏览与预览

- 只允许浏览 `config.yaml` 指定的沙盒根目录。
- 展示目录内容、类型、文件大小和修改时间；支持进入目录和返回上级。
- 文本类文件以转义后的纯文本预览；PDF 和常见图片可以内嵌预览；其他文件展示基本信息并提供下载。
- 文本预览受长度限制。Agent 当前的 PDF 内容检索范围仍是前两页；网页打开原 PDF 不代表检索已经覆盖全文。扫描件无 OCR。
- 网页文件浏览只读；文件整理仍由 Agent 工具执行。

### 安全与恢复

- 文件列表、预览和下载统一经沙盒路径校验；拒绝绝对路径、越界路径、隐藏内部目录和符号链接。
- 用户确认通过网页交互，覆盖当前的 `always`、`risky` 和 `never` 模式语义；拒绝操作后由 Agent 收到拒绝结果。
- 每轮写操作继续记录现有 oplog；界面展示运行 ID，并允许撤销该轮已记录的操作。
- API key 只由后端从环境变量读取，不发送给浏览器。
- 服务默认绑定 `127.0.0.1`，网页与 API 同源；如拆分部署，CORS 只放行明确配置的本机前端源。
- 会话数据库和 UI 状态位于沙盒之外，并加入 git 忽略规则。

## 页面结构

- 左栏：会话列表、“新建对话”按钮、最近更新时间。
- 中栏：消息列表、输入框、发送按钮、运行状态；工具调用和确认内容可展开。
- 右栏：沙盒文件浏览器和预览区，可收起；窄屏下改为侧栏。
- 不执行文件预览中的 HTML/脚本；Markdown 以纯文本或安全渲染方式显示。

## API 草案

| 方法与路径 | 行为 |
|---|---|
| `GET /api/health` | 返回服务状态和当前模型名称，不包含密钥 |
| `GET /api/conversations` | 返回会话摘要列表 |
| `POST /api/conversations` | 创建空会话 |
| `GET /api/conversations/{id}` | 返回会话消息与当前运行状态 |
| `POST /api/conversations/{id}/messages` | 添加用户消息并启动一轮 Agent，立即返回 `turn_id` |
| `GET /api/turns/{id}` | 返回运行状态、事件、待确认操作或最终结果 |
| `POST /api/turns/{id}/confirm` | 提交允许、拒绝或本轮全部允许 |
| `POST /api/turns/{id}/undo` | 撤销该轮 oplog 中的操作 |
| `GET /api/files?path=...` | 列出沙盒目录 |
| `GET /api/files/preview?path=...` | 返回受限长度的文本预览或文件元数据 |
| `GET /api/files/raw?path=...` | 内嵌显示 PDF/图片或下载文件 |

长任务使用后台线程执行，前端轮询 turn 状态。V1 不要求逐 token 流式输出；后续可用 SSE 推送状态和工具事件。

## 技术边界

- FastAPI 负责 HTTP、会话存储和运行调度；`AgentService` 适配 `run_agent`，并将终端确认转成网页确认等待。
- SQLite 保存会话元数据、完整模型历史和轮次状态；Agent 的 trace 与文件操作日志仍使用项目现有格式。
- 文件操作、内容检索和预览都调用现有沙盒与只读工具能力，不另行实现一套路径规则。
- UI 的状态摘要与模型内部历史分开：前端不展示 system prompt、密钥、原始 PDF 全文或隐藏目录。

## V1 暂不包含

账号与多用户权限、远程公网访问、文件上传、网页直接编辑文件、OCR、向量检索、移动端专门布局、逐 token 输出，以及对话删除/归档功能。

## 验收标准

- 新建两个会话后，彼此历史完全隔离；同一会话连续提问时 Agent 可以使用前文。
- 服务重启后能打开已保存对话并继续交互。
- 后端运行期间页面显示状态；遇到确认操作时可以允许或拒绝，拒绝后文件不被操作。
- 文件浏览器可浏览沙盒目录并预览文本、PDF 和图片；越界路径及隐藏内部目录不可访问。
- Agent 写操作的运行 ID 与操作日志关联，网页可触发对应 undo。
- 浏览器网络请求中没有 API key；服务默认仅监听本机回环地址。

## MVP 与后续

首个 MVP 采用单进程 FastAPI、内置静态 HTML/CSS/JavaScript、SQLite 和后台线程；通过短间隔轮询显示状态。它覆盖新建/恢复会话、连续对话、网页确认、undo 入口和沙盒文件预览。多用户、事件推送、任务取消和更丰富的文档格式留作后续。

## 对话展示增强（2026-10-18）

- `run_agent` 增加可选事件回调，实际发起模型请求、开始/完成工具调用时上报 `llm_start/llm_end/tool_start/tool_end`。CLI 不传回调时沿用原流程。事件不含模型的私有推理文本。
- 网页每约 650ms 获取运行状态，显示与当前调用对应的步骤，例如“检索论文内容”“阅读文件”；提供呼吸图标、文字微光、计时和可展开的步骤列表。确认等待期间显示暂停状态，任务完成后停止循环动画。关闭系统动画偏好时禁用动画。
- 最终答复出现时轻量淡入，当前模型接口仍一次性返回完整文本，不模拟逐 token 生成。运行状态和格式化均在本地完成，不额外调用模型。
- 回复通过 `markdown-it-py` 在后端渲染，支持 Markdown 标题、强调、列表、表格、引用和代码块。原始 HTML 禁用，未知链接协议不导航，Markdown 图片不自动请求远程资源。浏览器展示格式化 HTML，模型历史仍保存原始文本和完整工具消息。
- 文件引用规范为 `[显示名](sandbox:/相对路径)`，PDF 页码使用 `#page=N`。本地文件目录会核对路径、文件存在性和重名情况；有效引用显示为蓝色按钮，点击展开文件区并打开文件或 PDF 指定页。不存在、隐藏或链接到沙盒外的文件不能生成有效按钮，预览 API 仍独立校验路径。
- 为兼容旧对话，反引号中的完整路径以及普通文本中明确匹配的文件名也可转成按钮。同名文件需要完整相对路径；已经移动的旧路径可能失效，会显示无法打开。
- 路径识别优先使用磁盘上的准确路径；省略上级目录时可匹配唯一的目录后缀，例如 `强化学习/paper.pdf` 可定位到 `文献/强化学习/paper.pdf`。唯一匹配时兼容 Unicode 组合形式/连字、大小写和路径段首尾空格，最终按钮始终携带磁盘上的真实路径。重名或规范化后冲突时要求完整路径，不按文件名相似度猜测。
- 文件夹引用带独立类型标记，点击打开文件列表；文件引用打开文件预览。Markdown 链接若遗漏空格或括号的 URL 编码，仅在目标已核实存在时修正；代码示例保持原文。省略路径、移走文件和有歧义的引用提供具体失败提示。
- 切换对话时丢弃旧视图的迟到响应，避免运行中的步骤或文件记录串到其他对话；发送中的按钮立即禁用，防止重复提交。

## 可视化操作确认

- 确认器提供可选结构化回调，传递经过工具参数校验的操作名、参数和影响项数。网页由本地代码构建确认清单，不再展示或解析终端的 Python 列表、`y/n/a` 提示文本；CLI 继续使用原有文本提示。
- 紧凑卡片展示操作标题、摘要、分组数量和文件入口。批量去重按实际重复组排列，同一组内放置保留文件与待回收副本，每项带文字标签；待回收文件卡片和预览标题使用浅红色，选中后保留红色提示。移动和重命名展示原文件与目标路径；新建文件夹显示计划路径。扩展名变化或文件夹包含后代文件时给出具体说明。
- 重复组关系从本地执行计划原样传入，包括用户指定的保留项，以及近似版本家族内实际执行的确定重复子组，不通过文件名或列表顺序猜测配对。旧请求缺失组关系时展示完整混合清单并提示核对，不隐藏操作涉及的文件。
- “展开核对”打开独立对话框：左侧完整清单可滚动，右侧显示所选 PDF、图片或文本；支持查看文件夹内容和打开/下载原文件。点击蓝色文件入口直接打开核对窗口及对应预览，不触发写操作。
- 核对窗口底部固定显示“拒绝此次操作”和具体操作的确认按钮。默认只允许当前操作；可主动勾选“本轮后续操作免确认”，沿用已有 `a` 语义。关闭或按 Escape 只关闭预览窗口，Agent 继续等待确认。
- 每次确认使用唯一 ID，阻止旧窗口提交到下一次确认；提交中禁止重复点击。预览只走现有受沙盒限制的读取 API，已不存在、隐藏或符号链接路径不给有效预览入口。新文件夹创建前不提供文件预览。

## 耗时与执行优化（2026-10-18）

- `seconds` 保留墙钟总时间；新增 `active_seconds`、`wait_seconds`、`llm_seconds`、`tool_seconds`。确认器以单调时钟累计等待；本地工具耗时扣除同一段等待。网页实时计时由服务端单调时钟快照驱动，等待确认时暂停，完成后显示分项。旧记录明确标注含等待，不用秒级事件反推精确数据。
- 请求只有项目层重试（默认一次），SDK 自动重试为零。每次尝试的开始/结束、错误类型、退避时间及成功响应的输入/输出/缓存 Token 写入 trace，可从详情 API 的 `requests` 查看；失败轮次同样留下计时。非流式调用不能细分网络、服务端排队与逐 Token 生成时间。
- 全文查重缓存跨 `Sandbox` 实例共享，按沙盒根目录和设备/inode/大小/mtime/ctime 隔离；`text` 与 `near` 复用提取特征。缓存仅驻留进程，LRU 上限 512 条、载荷预算约 64 MiB，不保存全文到磁盘；异常不缓存。写计划仍是当前运行内临时对象，确认前后 SHA256 校验照常执行。
- `apply_dedup` 在本地确认原位置移除、回收文件存在、保留文件指纹一致。仅针对所选计划报告成功，外部修改或失败仍要求核实；默认不追加全量扫描。
- Web 在新任务入口对超过 40000 JSON 字符的模型历史做本地投影；最近两个完整任务保留工具消息，较早任务保留用户指令、助手文字和写操作结果，归档旧调用/结果对。完整历史仍写入 SQLite、供网页展示；不在每个模型轮次改写前缀，也不启用旧实验中的逐轮压缩。此策略可能减少远端前缀缓存命中，实际费用/端到端耗时需后续实测。
- 撤销将实际报告作为文件状态事件写入所有已有对话；原位置冲突等跳过项不写成还原成功。重复请求返回第一次报告，内存与 SQLite 同步。存在运行任务时拒绝撤销以防共享沙盒竞争。旧数据在下一次发送时补录撤销时间，并标明历史事件之后可能已有新操作。
