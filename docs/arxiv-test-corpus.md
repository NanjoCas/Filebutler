## 规模与采样

目标 80 篇：机器学习、自然语言处理、视觉、系统、安全、数学、物理、天体物理、定量生物、金融经济共 10 个方向，每方向 8 篇。

本次前 16 篇由 arXiv Atom API 按类别和首次提交日期查询得到：机器学习和语言方向，各 4 篇来自 2015–2020 与 2023–2025 时间窗，按提交日期降序选择。之后搜索 API 持续返回 429/503，遵守退避等待后仍未恢复，因此停止搜索请求，剩余方向改为明确的 arXiv ID 清单，直接读取官方摘要页元数据并下载 PDF。视觉包括 ResNet、VGG、YOLO、ViT 等；其他方向覆盖系统、隐私安全、随机过程与最优传输、量子多体、暗物质、基因表达与蛋白质、金融风险与投资组合。

因此最终语料属于人工选择与类别采样混合，不是随机样本，不是年份均匀采样；各方向也不再承诺各时间窗恰好四篇。实际标题、年份和版本以 manifest 为准。默认 curated 模式无需搜索 API；可选 `--selection api` 保留原始查询方式。重新从空目录下载可能获取当时的最新版本；严格复现当前文件应使用 manifest 中固定的版本 URL 与 SHA256。

arXiv 类别存在交叉；文件夹方向是采样桶，不一定等于论文的 arXiv 主类别。API 结果保存全部原始类别；摘要页模式保存主类别，交叉类别可查缓存 HTML。不同方向之间不会重复下载同一 arXiv 论文族。方向标签只用于分层采样，不能当作人工验证的论文方法分类答案。

每方向 6 篇进入 development、2 篇进入 holdout，合计 60/20。前两方向保留各时间窗前三篇 development、第四篇 holdout 的规则；其余方向按成功接受的顺序，前六篇 development、后两篇 holdout。这个划分只保证本批内部没有同一 arXiv 论文族跨集合；并未证明和模型训练数据无重叠。真正运行盲测前还需冻结问题与人工答案，避免查看留出集后继续调整提示词。

## 输出

- `papers/<方向>/<arxiv_id含版本>.pdf`：从 arXiv 下载的原始 PDF，保留原始字节。
- `manifest.json`：标题、作者、摘要、arXiv 类别、具体版本、来源 URL、时间、哈希、逐页文字量及抽取状态。
- `manifest.csv`：方便浏览和外部工具使用的简表。
- `metadata/*.xml` 与 `*.html`：原始 arXiv Atom 查询响应或官方摘要页，记录候选、元数据和版本来源。
- `summary.json`：实际数量、大小、页数、分组数量和失败记录数量。

脚本串行联网，两次请求开始时间至少间隔 6 秒；收到 429/503 后遵守 Retry-After 或至少等待 60 秒再重试。下载有超时、重试、40 MiB 单文件上限和 PDF 头/打开检查；PDF 失败会写入 manifest 并从候选继续补足，元数据请求失败则停止并保留断点。重跑使用已缓存的元数据，实际版本由 manifest 和 PDF 哈希固定，而不是依赖将来重新查询的结果。

## 使用边界

这批资料适合测试跨主题分类、英文全文检索、中文查询英文资料、元数据提取和长文档处理。它没有人为加入重复副本，也没有保证包含扫描件、中文正文或已验证的多版本组；后续若需要这些场景，应明确新增并标注，不能声称本批已经覆盖。

PDF 打开和文字抽取检查只验证基本可用性，不证明公式、表格和阅读顺序解析正确。语义标准答案仍需独立人工审核。

评测写操作时使用临时副本，原始语料保留。若只需在网页查看，可将 `config.yaml` 的 sandbox 指向本数据集的 `papers/`，但这会让写操作直接影响该语料；更推荐在临时工作区复制后使用。新的目录布局与旧 `papers.labels.yaml` 不同，不能直接将旧的六项分类评测当作新语料评测。

使用与来源：[arXiv API 使用规则](https://info.arxiv.org/help/api/tou.html)。PDF 用于本地研究和测试；每篇的再分发条件需查看其 arXiv 摘要页许可。Atom API 未提供逐篇许可时，manifest 将 license 留空并保存查阅入口；摘要页模式会提取该页面公开的许可链接。
